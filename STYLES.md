# STYLES.md — Визуална палитра STORA

Референтен файл за цветовете на проекта. Ползвай тези стойности при UI
работа (заедно с `frontend-design` скила, виж CLAUDE.md), вместо да
измисляш нови цветове ad-hoc.

## Произход

Извлечено от палитра, избрана от потребителя (folder+accent икона) —
циан/синьо като основен тон, зелено като success/потвърждение акцент.
Посока: съвременен, "мек" вид, близък до Material 3 Expressive (Android
16) / iOS 18-19 естетика — заоблени форми, layered повърхности, светла
основа — а не тъмния till-дисплей стил на текущия checkout модал
(`--pos-*` в sale_add.html). Ако тази палитра замества pos-тематиката
навсякъде, а не само за нови екрани, реши изрично с потребителя преди
Claude Code да пипа вече готовия checkout modal.

## Цветове

```css
:root {
  /* Основен акцент (циан/синьо) — бутони, активни табове, header */
  --brand-cyan-light: #4DD9F5;   /* основна повърхност */
  --brand-cyan-mid:   #3BB8E8;   /* hover/преход */
  --brand-blue-deep:  #2B6FD1;   /* тъмен акцент, ъглови детайли */

  /* Success / потвърждение (зелено) — Complete Sale, добавен продукт и т.н. */
  --brand-green-light: #2FAE6B;
  --brand-green-deep:  #1E7A4C;

  /* Неутрални */
  --brand-white: #FFFFFF;
}
```

## Насоки за употреба

- **Циан/синьо** → primary действия, навигация, активно състояние (табове,
  избран елемент).
- **Зелено** → само success/потвърждение семантика — не общ декоративен
  цвят. Съответства на съществуващия `--pos-cash` акцент в checkout модала
  (`#2f6f4f`), така че двете палитри не си противоречат семантично, дори
  visually да се различават.
- **Бяло** → текст върху наситени/тъмни повърхности, основен фон при
  светла тема.
- Заоблени ъгли навсякъде (16-24px+), pill-shaped бутони, меки/дифузни
  сенки — не остри ъгли, не плосък Bootstrap вид.

## Референции за формата/spacing посоката

Палитрата по-горе дава цветовете; тези линкове дават конкретни стойности
за форма, radius, spacing, elevation (по-точно от снимки за вдъхновение):

- **Material 3 Expressive** (Android 16) —
  https://m3.material.io/blog/material-3-expressive — секции "Shape" и
  "Color".
- **Apple Human Interface Guidelines** —
  https://developer.apple.com/design/human-interface-guidelines — секция
  "Materials" (layered повърхности / liquid glass).

Ако линк не се зарежда добре в дадена сесия, алтернатива е реален
screenshot от Material 3 / iOS 18+ приложение (не икона/лого — истински
екран с бутони и карти), пуснат директно като референтна снимка.

## Извън обхват

- **`.pos-header` (касовия хедър) НЕ се пипа** — потребителят харесва
  текущия вид (виж CLAUDE.md, "Хедърът вече не е плътна синя лента зад
  New Sale" — вече мина отделен дизайн pass, потвърден с потребителя).
  Тази палитра важи за нови/предстоящи екрани, не за ретроактивно
  пренаписване на вече одобрени части.

(Добавяй нови цветове/варианти тук, когато изникнат в разговор с
потребителя — както CLAUDE.md пази работни правила, тоя файл пази
визуални решения, за да не се преоткриват на всяка сесия.)
